# Pages source à moderniser

Déposez ici le **code Gutenberg complet** de chaque page (un fichier `.html` ou `.txt` par page),
par ex. `nos-prestations.txt`, `prestation-creation-site.txt`.

Pourquoi : le chat tronque les messages > ~50 000 caractères ; plusieurs pages dépassent cette
limite et arrivent coupées. En fichier, je lis la page entière et je produis la version
modernisée dans `Gutenberg/page-<nom>.html`.

Ces fichiers (et tout le dossier `Gutenberg/`) sont exclus du ZIP de production.

# GEO Analyzer

Le **GEO Analyzer** est un outil intégré à l’**éditeur Gutenberg** (pages et articles). Il aide à améliorer la **clarté** et la **structure** du contenu pour qu’il soit mieux compris ou cité par des outils d’IA (approche « Generative Engine Optimization », GEO).

## Ce que ce n’est pas

- Ce n’est **pas** un référencement Google classique (voir plutôt [SEO Helper](seo-helper.md) pour les bases titre / meta / structure).
- Ce n’est **pas** une garantie de positionnement : c’est une **aide à la rédaction** et à la structuration.

## Activer ou désactiver l’outil

1. Allez dans **Apparence → Options G2RD**.
2. Onglet **Clients**.
3. Utilisez le réglage **Activer l’aide GEO dans l’éditeur**.

Si l’option est désactivée, le panneau GEO n’apparaît plus dans l’éditeur.

## Comment l’utiliser dans l’éditeur

1. Éditez une **page** ou un **article**.
2. Ouvrez la **barre latérale** de l’éditeur (icône « engrenage » ou équivalent selon votre WordPress).
3. Cherchez le panneau **GEO Analyzer** (souvent listé avec les autres extensions d’éditeur).

Le panneau calcule un **score** (sur 100) à partir du contenu : structure des blocs de texte, titres, éléments utiles à l’IA, etc. Un bouton de **rafraîchissement** permet de recalculer après vos modifications.

## Lien avec le « type de site »

Dans **Apparence → Options G2RD → Configuration**, le **Type de site** (vitrine, leads, e-commerce…) oriente aussi certaines recommandations affichées dans le thème. Pour le détail, voir [Mode Business](mode-business.md).

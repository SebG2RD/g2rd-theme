# SEO Helper

Le **SEO Helper** affiche dans l’éditeur Gutenberg des **indicateurs légers** pour ne pas oublier les bases du référencement : titre, méta-description, structure des titres, etc.

## Ce que ce n’est pas

Ce n’est **pas** un plugin SEO complet (type Yoast ou Rank Math). Il **complète** une bonne pratique éditoriale mais ne remplace pas une stratégie SEO globale ni un suivi de mots-clés avancé.

## Pour quels contenus

Le panneau est prévu pour les types de contenu classiques **articles** et **pages** dans l’éditeur. Sur d’autres types de publication, il peut ne pas se charger.

## Activer ou désactiver

1. **Apparence → Options G2RD**
2. Onglet **Clients**
3. **Activer l’aide SEO dans l’éditeur**

## Utilisation

1. Ouvrez une page ou un article.
2. Dans la **barre latérale** de l’éditeur, repérez le panneau du SEO Helper.
3. Corrigez les points signalés (titre trop court, méta-description manquante, etc.) puis enregistrez la page.

Certaines analyses peuvent faire appel au **serveur** (REST) pour des vérifications complémentaires : vous devez rester connecté avec un compte autorisé à modifier le contenu.

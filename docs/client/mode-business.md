# Mode Business (type de site)

Le **mode Business** ne change pas brutalement le design du site visiteur : il sert surtout à **orienter les conseils** et recommandations affichés aux personnes qui travaillent dans l’administration et dans l’**éditeur de blocs**.

## Choisir un type de site

1. Allez dans **Apparence → Options G2RD**.
2. Onglet **Configuration**.
3. Section **Type de site** — choisissez une carte :

   - **Site vitrine** — présenter une activité (pages services, à propos, contact).
   - **Génération de leads** — mettre l’accent sur la conversion (formulaires, offres).
   - **E-commerce** — boutique, panier, confiance acheteur.
   - **Non défini** — aucune recommandation spécifique liée au type.

4. Cliquez sur **Enregistrer** en haut de la page des options si vous avez modifié d’autres réglages.

## Effets concrets

Selon le type choisi, le thème peut :

- injecter des **données d’aide** dans l’éditeur (conseils, type de CTA suggéré, idées de pages ou de patterns) ;
- afficher un **widget** sur le tableau de bord WordPress avec des rappels utiles ;
- afficher des **notices** d’orientation dans l’administration.

Cela aide les équipes à rester cohérentes avec l’objectif du site (vitrine vs leads vs vente en ligne).

## Lien avec GEO

La même page **Configuration** indique que le type de site **oriente les recommandations GEO**. Pour le panneau de score, voir [GEO Analyzer](geo-analyzer.md).

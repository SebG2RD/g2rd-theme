# Activation de la licence

La **licence** relie votre site au service G2RD : elle permet notamment les **mises à jour automatiques** du thème et le déblocage complet des **blocs G2RD** dans l’éditeur (selon votre offre).

## Où trouver votre clé

Après achat, la clé est généralement disponible dans **votre espace client** sur la boutique G2RD (gestion via **FluentCart**). Vous pouvez aussi la recevoir par e-mail de confirmation.

> **SureCart** : certaines anciennes commandes peuvent encore y être liées pour compatibilité ; les **nouvelles** licences passent par FluentCart. En cas de doute, contactez le support de votre achat.

## Activer la licence sur le site

1. Connectez-vous en tant qu’**Administrateur**.
2. Allez dans **Apparence → Options G2RD**.
3. Ouvrez l’onglet **Licence**.
4. Collez votre **clé de licence** dans le champ prévu.
5. Cliquez sur le bouton d’**activation** (libellé du type « Activer la licence »).

En cas de succès, l’écran affiche un statut du type **Active** et souvent un aperçu masqué de la clé (pour confirmer qu’une clé est bien enregistrée sans l’afficher en entier).

## Désactiver la licence

Si vous déplacez le site vers un **autre nom de domaine**, il est souvent nécessaire de **désactiver** la licence sur l’ancien site avant de l’activer sur le nouveau (voir [FAQ licence](faq-licence.md)).

La désactivation se fait depuis le même onglet **Licence**, avec une confirmation avant envoi au serveur de licences.
